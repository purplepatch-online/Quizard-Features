\chapter{The Performance Rating Architecture: 6 Score Bands, Dynamic Deltas, and Progression Modeling}

\begin{tcolorbox}[storybox, title={The Rating Engine in Brief}]
A contestant's skill rating is bounded strictly as an \textbf{integer on the 0 to 60 tournament scale} ($0 \le R \le 60$). Instead of raw score spikes or decimal fractions, Quizard implements an integer-based dynamic rating engine calibrated on a linear sensitivity scale: \textbf{Rating Delta is calculated simply as $\mathbf{\Delta R = \text{round}(0.6 \times \Delta S)}$}. Every round score ($S \in \{0, 1, \dots, 60\}$) dynamically pulls the player's integer rating up or down, directly determining their active competitive rank tier.
\end{tcolorbox}

\section{The Integer Dynamic Rating Update Formula ($\Delta S \times 0.6$)}
Upon completing a round with raw score $S_{t+1} \in \{0, \dots, 60\}$, the integer delta $\Delta R$ is calculated directly from the score gap $\Delta S = S_{t+1} - R_t$ using the standardized 60\% sensitivity coefficient:

\begin{equation}
\Delta S = S_{t+1} - R_t
\end{equation}

\begin{equation}
\Delta R = \text{round}\big(0.6 \cdot \Delta S\big) = \text{round}\big(0.6 \cdot (S_{t+1} - R_t)\big)
\end{equation}

The updated integer rating $R_{t+1}$ is clamped strictly between 0 and 60:

\begin{equation}
R_{t+1} = \text{clamp}\big(0, \, 60, \, R_t + \Delta R\big)
\end{equation}

\subsection{Core Principles of the $0.6 \times \Delta S$ Engine}
\begin{itemize}
    \item \textbf{Direct and Intuitive Math:} Rating changes are proportional to 60\% of the performance gap ($\Delta S = S - R$). There are no complex piecewise arbitrary splits.
    \item \textbf{Strict Integer Scale ($0 \le R \le 60$):} Standard rounding ($\text{round}(\cdot)$ using midpoint away from zero) ensures all rating values, deltas, and tier thresholds remain whole integers for clean badge rendering.
    \item \textbf{Symmetric Accountability:} Outperforming your current rating by $+10$ points yields $\text{round}(0.6 \times 10) = +6$ rating points. Conversely, underperforming by $-10$ points deducts $-6$ rating points.
    \item \textbf{Natural Convergence:} As a player's skill stabilizes around their true score (e.g., scoring $34$ with a rating of $34$), $\Delta S = 0 \implies \Delta R = 0$, holding their rank solid.
\end{itemize}

\subsection{Detailed Analysis of Each Case}
\begin{enumerate}
    \item \textbf{Case A: Score 32 (Slightly Below Rating):}
    $$\Delta S = 32 - 34 = -2 \implies \Delta R = \text{round}(0.6 \times -2) = -1 \implies R_1 = 34 - 1 = \mathbf{33}$$
    \textit{Outcome:} Rating gently softens from 34 to 33, remaining securely within the Specialist band ($30-39$).

    \item \textbf{Case B: Score 36 (Slightly Above Rating):}
    $$\Delta S = 36 - 34 = +2 \implies \Delta R = \text{round}(0.6 \times 2) = +1 \implies R_1 = 34 + 1 = \mathbf{35}$$
    \textit{Outcome:} Beating current expectation awards $+1$ point, climbing to 35.

    \item \textbf{Case C: Score 38 (Strong Specialist Round):}
    $$\Delta S = 38 - 34 = +4 \implies \Delta R = \text{round}(0.6 \times 4) = +2 \implies R_1 = 34 + 2 = \mathbf{36}$$
    \textit{Outcome:} High accuracy accelerates upward momentum, climbing to 36.

    \item \textbf{Case D: Score 52 (Master Breakout Performance):}
    $$\Delta S = 52 - 34 = +18 \implies \Delta R = \text{round}(0.6 \times 18) = +11 \implies R_1 = 34 + 11 = \mathbf{45} \quad (\text{Promoted to Expert!})$$
    \textit{Outcome:} Scoring 52 correct produces an immediate $+11$ leap, catapulting Mahir directly into the \textbf{Expert} Tier.

    \item \textbf{Case E: Score 12 (Severe Drop / Abandonment):}
    $$\Delta S = 12 - 34 = -22 \implies \Delta R = \text{round}(0.6 \times -22) = -13 \implies R_1 = 34 - 13 = \mathbf{21}$$
    \textit{Outcome:} Quitting early or scoring 12 triggers a substantial $-13$ integer penalty, demoting the player down to \textbf{21 (Apprentice)}.
\end{enumerate}

\section{Database Schema and Clean Architecture Implementation}

\subsection{1. PostgreSQL Historical Rating Table}
\begin{lstlisting}[language=SQL, caption={PostgreSQL Schema for Integer Rating History}]
CREATE TABLE participant_rating_history (
    id BIGSERIAL PRIMARY KEY,
    msisdn VARCHAR(15) NOT NULL,
    portal_id INT NOT NULL DEFAULT 15,
    event_id INT NOT NULL,
    round_score INT NOT NULL, -- 0 to 60
    rating_before INT NOT NULL CHECK (rating_before BETWEEN 0 AND 60), -- e.g. 34
    rating_delta INT NOT NULL,  -- e.g. +1, -1, +11, -13
    rating_after INT NOT NULL CHECK (rating_after BETWEEN 0 AND 60),   -- e.g. 45 (strictly integer 0 to 60)
    band VARCHAR(30) NOT NULL, -- 'Novice', 'Apprentice', 'Specialist', 'Expert', 'Master', 'Grandmaster'
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_rating_history_lookup ON participant_rating_history (msisdn, portal_id, created_at DESC);
\end{lstlisting}

\subsection{2. .NET 10 Domain Rating Calculator Implementation}
\begin{lstlisting}[language={[Sharp]C}, caption={C\# 13 Implementation of the $0.6 \times \Delta S$ Engine}]
namespace Quizard.Domain.Services;

public static class RatingCalculator
{
    public const int MinRating = 0;
    public const int MaxRating = 60;
    public const double Sensitivity = 0.60;

    public static int CalculateDelta(int currentRating, int roundScore)
    {
        currentRating = Math.Clamp(currentRating, MinRating, MaxRating);
        roundScore = Math.Clamp(roundScore, MinRating, MaxRating);

        int gap = roundScore - currentRating;
        return (int)Math.Round(Sensitivity * gap, MidpointRounding.AwayFromZero);
    }

    public static int CalculateNewRating(int currentRating, int roundScore)
    {
        int delta = CalculateDelta(currentRating, roundScore);
        return Math.Clamp(currentRating + delta, MinRating, MaxRating);
    }
}
\end{lstlisting}

\begin{tcolorbox}[summarybox, title={Chapter Key Takeaways}]
\begin{itemize}
    \item The rating is calculated simply and transparently as \textbf{$\mathbf{\Delta R = \text{round}(0.6 \times \Delta S)}$}, providing predictable and responsive competitive progression.
    \item Ratings and tier boundaries are strictly integers between $0$ and $60$, providing clean alignment with the 60-question match length.
    \item Rapid promotions reward breakout performances, while consistent performance preserves elite Master ($50-59$) and Grandmaster ($60$) status.
\end{itemize}
