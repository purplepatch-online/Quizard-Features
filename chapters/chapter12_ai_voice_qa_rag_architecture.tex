\chapter{AI Voice Q&A, Bengali NLP, and Retrieval-Augmented Generation (RAG)}

\begin{tcolorbox}[storybox, title={The Story of Arif's Voice-Guided BCS Revision}]
Arif is an aspiring civil service candidate commuting on a crowded bus from Gazipur to Dhaka. Unable to type on his screen, Arif connects his Bluetooth earbuds and activates Quizard's **AI Voice Q&A Assistant**:

\begin{enumerate}
    \item \textbf{Voice Query:} Arif speaks in Bengali into his microphone: \textit{``Ask me 5 hard questions about the 1971 Liberation War Constitution history.''}
    \item \textbf{High-Speed Transcription ($< 80\text{ms}$):} A localized **Whisper-Small** acoustic model transcribes his spoken Bengali into text with accurate punctuation.
    \item \textbf{RAG Vector Retrieval ($< 25\text{ms}$):} The system queries an enterprise vector database (\texttt{pgvector} with BGE-M3 embeddings) indexing official Bangladesh National Curriculum (NCTB) textbooks and historical records.
    \item \textbf{Small Local LLM Generation ($< 120\text{ms}$):} A self-hosted **Qwen 2.5 7B-Instruct** model synthesizes fact-checked trivia with zero hallucinations.
    \item \textbf{Audio Playback ($< 90\text{ms}$):} A natural Bengali neural Text-to-Speech (TTS) engine reads the question and choices directly into Arif's ear, allowing him to answer by voice.
\end{enumerate}
In less than **320 milliseconds**, Arif experiences a hands-free, interactive study session powered by sovereign AI.
\end{tcolorbox}

\subsection{Architectural Recommendation: The Hybrid AI Strategy}
\begin{enumerate}
    \item \textbf{Small Local Model for Online Live Q\&A (Production Winner):} For real-time voice conversations and live player interactions, self-hosted **Qwen 2.5 7B-Instruct** (or **Llama 3.2 3B-Instruct**) running on `vLLM` delivers sub-100ms responses with **zero API costs**.
    \item \textbf{Large Cloud Model for Offline Batch Ingestion:} Cloud LLMs (e.g. Gemini 1.5 Flash) are utilized strictly as an asynchronous offline tool to ingest whole textbooks and generate thousands of pre-verified questions into the CMS database.
\end{enumerate}

\section{PostgreSQL Vector Schema Implementation}

\begin{lstlisting}[language=SQL, caption={PostgreSQL pgvector Schema for Trivia RAG Embeddings}]
-- Enable pgvector extension
CREATE EXTENSION IF NOT EXISTS vector;

-- Textbook & Syllabus Knowledge Chunks Table
CREATE TABLE curriculum_knowledge_chunks (
    id BIGSERIAL PRIMARY KEY,
    category_id INT NOT NULL,
    source_book VARCHAR(150) NOT NULL,
    chapter_topic VARCHAR(150) NOT NULL,
    chunk_content TEXT NOT NULL,
    embedding VECTOR(1024), -- BGE-M3 multilingual dense embedding
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- HNSW Vector Index for Sub-Millisecond Cosine Similarity Search
CREATE INDEX idx_curriculum_embedding_hnsw 
ON curriculum_knowledge_chunks 
USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
\end{lstlisting}
