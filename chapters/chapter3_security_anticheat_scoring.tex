\chapter{The Shield of Integrity: Cryptography, Anti-Cheat, and Score Persistence}

\begin{tcolorbox}[storybox, title={The Security Engine in Brief}]
Because real monetary prizes (e.g., 10,000 BDT to 25,000 BDT) are awarded to top tournament rankers, tournament integrity is paramount. Quizard implements a military-grade security barrier: end-to-end AES-256-CBC encrypted score payloads, server-authoritative identity enforcement, and real-time anti-cheat velocity heuristics that instantly detect bots and clock manipulation.
\end{tcolorbox}

\section{The End-to-End Cryptographic Handshake}
When a player finishes their 60-question round, the client app does not transmit plain text scores over the network. If plain JSON were sent, any user with basic browser developer tools could intercept the network request and change their score to 60 in 1 second.

Quizard secures the transmission using **AES-256-CBC Payload Cryptography**:

\section{The Multi-Layer Anti-Cheat Verification Suite}
The server's \texttt{AntiCheatService} examines every decrypted play through 5 heuristic checks before accepting a score:

\begin{enumerate}
    \item \textbf{Human Velocity \& Answering Speed Limit:}
    $$\text{Answer Velocity} = \frac{\Delta \text{Score}}{\Delta \text{Time Taken}} \le 1.5 \text{ answers / second}$$
    Human cognitive processing requires at least $0.66\text{ seconds}$ to read a question, parse 4 options, and tap the screen. If a submission claims 60 correct answers in 2 seconds, the calculated velocity ($30\text{ ans/sec}$) fails the limit, immediately tagging the record as \texttt{SUSPICIOUS} with reason \texttt{"Impossible answer speed"}.
    
    \item \textbf{Timer Consistency \& Server Gap Verification:}
    $$\Delta \text{Time Taken} \le 10 \times \Delta \text{Server Timestamp Gap}$$
    Ensures the client's internal clock did not pause, jump, or accelerate abnormally compared to real-world server time.
    
    \item \textbf{Timer Rollback Protection:}
    $$\Delta \text{Time Taken} \ge -10\text{ seconds}$$
    Prevents malicious scripts from resetting or rolling back elapsed time during a live round.
    
    \item \textbf{Score Monotonic Progression:}
    $$\Delta \text{Right Count} \ge 0$$
    A contestant's cumulative score within a single round cannot decrease between checkpoints.
    
    \item \textbf{Attempt Flooding \& Reset Spam Cap:}
    Caps daily attempts at \texttt{MAX\_ATTEMPTS\_PER\_DAY} and detects automated reset loops ($>10$ consecutive zero-second resets).
\end{enumerate}

\section{Two Divergent Journeys: Salma vs. Tanvir}

\subsection{Salma's Legitimate Victory (59/60 in 150 Seconds)}
In Sylhet, Salma starts her second tournament attempt of the day. Over 150 seconds, she steadily answers 60 rapid questions across all difficulty tiers.

When the round completes:
\begin{enumerate}
    \item Her phone generates an encrypted AES-256 payload and submits it to \texttt{/api/participant/quizplay\_result\_submit/}.
    \item The backend decrypts the payload: \texttt{Score: 59}, \texttt{Time Taken: 150s}, \texttt{Round: 2}, \texttt{Event: 34}.
    \item \texttt{AntiCheatService} computes her answering velocity:
    $$\text{Velocity} = \frac{59\text{ answers}}{150\text{ seconds}} = 0.393\text{ answers/sec} \le 1.5 \implies \textbf{PASSED}$$
    \item The record is saved to \texttt{quizapp\_quizplaysummery} with $\texttt{is\_valid} = 1$ and $\texttt{status} = \text{"VALID"}$.
    \item Salma takes the \textbf{\#1 Rank} on the live tournament leaderboard!
\end{enumerate}

\subsection{Tanvir's Automated Exploit Attempt (Flagged \& Blocked)}
Meanwhile, a tech-savvy user named Tanvir attempts to use an automated browser script to send forged quiz results. His script submits a forged score claiming **60 correct answers in only 2 seconds**.

\begin{enumerate}
    \item The backend receives and decrypts Tanvir's payload: \texttt{Score: 60}, \texttt{Time Taken: 2s}.
    \item \texttt{AntiCheatService} runs the velocity check:
    $$\text{Velocity} = \frac{60\text{ answers}}{2\text{ seconds}} = 30.0\text{ answers/sec} > 1.5 \implies \textbf{FAILED}$$
    \item The backend persists the record with $\texttt{is\_valid} = 0$, $\texttt{status} = \text{"SUSPICIOUS"}$, and $\texttt{reason\_msg} = \text{"Impossible answer speed"}$.
    \item When the leaderboard queries today's rankings (\texttt{WHERE is\_valid = 1}), Tanvir's record is completely ignored. Honest players like Salma and Rahim remain protected at the top of the leaderboard!
\end{enumerate}

\begin{tcolorbox}[summarybox, title={Chapter Key Takeaways}]
\begin{itemize}
    \item All score submissions are sealed client-side using **AES-256-CBC** cryptography before network transmission.
    \item The server strictly overrides user identity from the authenticated JWT/Bearer token, preventing MSISDN spoofing.
    \item \texttt{AntiCheatService} applies real-time human speed and timer consistency heuristics, ensuring fraudulent submissions are tagged \texttt{is\_valid = 0} and excluded from official prize leaderboards.
\end{itemize}
