\chapter{The XP Ledger, Daily Streaks, and Milestone Achievement System}

\begin{tcolorbox}[storybox, title={The Retention Gamification Engine in Brief}]
A 15-day live data review revealed that the majority of players churn after a single session. To cultivate enduring daily return habits, Quizard implements an Experience Point (XP) system powered by an immutable transaction ledger, daily consistency streak rewards ($+20\text{ XP/day}$), a giant 15th-day milestone surge ($+500\text{ XP}$), and collectible achievement badges.
\end{tcolorbox}

\section{Core Experience Point (XP) Earning Mechanics}
XP serves as Quizard's primary engagement currency, separate from competitive tournament scores. It is awarded for participation and daily consistency:

\begin{itemize}
    \item \textbf{Daily First-Play Bonus:} $+50\text{ XP}$ awarded on the contestant's first tournament round of the day.
    \item \textbf{Round Completion Base XP:} $+10\text{ XP}$ awarded upon completing each 60-question match.
    \item \textbf{Answer Accuracy Bounty:} $+1\text{ XP}$ per correct answer ($\text{RightCount} \le 60$).
\end{itemize}

\section{Daily Streaks with the Giant 15th-Day Surge}
To foster an intuitive and predictable daily habit loop, contestants earn a consistent reward of **$+20\text{ XP}$ each day** for maintaining their daily streak, culminating in a **giant $+500\text{ XP}$ milestone surge on the 15th consecutive day**.

\subsection{Daily Streak Rule}
For every consecutive active day $n$:
\begin{equation}
\text{Streak XP}(n) = 
\begin{cases} 
20\text{ XP} & \text{if } n \neq 15 \\
520\text{ XP} & \text{if } n = 15 \quad (\text{Base } 20 + 500\text{ Milestone Surge})
\end{cases}
\end{equation}

\subsection{1. Buying Extra Tournament and Game Rounds (Daily Cap Bypass)}
Under standard rules, contestants are restricted to 2 tournament attempts per day. Once daily rounds are exhausted, players can spend XP to immediately unlock an extra round without waiting for the midnight reset:
\begin{itemize}
    \item \textbf{Tournament Extra Round (Event 150):} Costs \textbf{150 XP} per additional attempt.
    \item \textbf{Casual Wordly / Memory Match Extra Life:} Costs \textbf{100 XP} to play a second daily puzzle.
    \item \textbf{Architecture Mechanism:} The backend creates an authorized \texttt{ondemand > 0} session in \texttt{quizapp\_quizplaysummery} and registers a corresponding debit entry in \texttt{participant\_xp\_ledger} with source \texttt{'burn\_extra\_round'}.
\end{itemize}

\subsection{2. In-Game Tactical Lifelines and Power-Ups}
During high-stakes 60-question tournament matches, contestants can deploy tactical lifelines by spending XP:
\begin{itemize}
    \item \textbf{50-50 Lifeline (50 XP):} Instantly eliminates two incorrect answer options on any single challenging question, leaving the correct option and one distractor.
    \item \textbf{Time Freeze (+15s Extension) (75 XP):} Adds 15 extra seconds to the countdown clock when time pressure is severe.
    \item \textbf{Second Chance / Mulligan (100 XP):} Re-activates a single question that was answered incorrectly, allowing the player to choose again without penalty.
\end{itemize}

\subsection{3. Streak Freeze and Protection Shields}
Daily streaks are fragile: missing a single calendar day resets a 14-day streak to Day 1, destroying the anticipation of the $+500\text{ XP}$ Half-Month Titan milestone. Contestants can purchase insurance:
\begin{itemize}
    \item \textbf{Streak Freeze Shield (300 XP):} Protects an active streak for 24 hours if the player fails to play due to travel or network outage.
    \item \textbf{Retroactive Streak Recovery (500 XP):} Allows a player who broke their streak yesterday to restore their previous streak count within 48 hours.
\end{itemize}

\subsection{4. High-Stakes VIP and Championship Tournament Buy-Ins}
Quizard hosts weekend mega-tournaments with cash prize pools exceeding \textbf{50,000 BDT}. While entry normally requires a premium bKash subscription, contestants can use accumulated XP as an entry buy-in:
\begin{itemize}
    \item \textbf{Championship Arena Buy-In (500 XP):} Grants an entry pass to the Saturday Night Live Tournament.
    \item \textbf{Grandmaster Blitz Invitational (350 XP):} Unlocks access to the speed-quiz arena with 10-second rapid question intervals.
\end{itemize}

\subsection{5. Exclusive Profile Cosmetics, Badges, and Themes}
XP unlocks vanity customization items that let players display their status on the live leaderboards:
\begin{itemize}
    \item \textbf{Animated Avatar Frames:} Glowing Bronze (200 XP), Emerald Fire (400 XP), Grandmaster Dragon (1,000 XP).
    \item \textbf{Custom UI Themes:} Cyberpunk Neon, Imperial Royal Gold, and Deep Night OLED skins (300 XP each).
    \item \textbf{Custom Honorific Titles:} Displays badges like \textit{``Trivia Sultan''} or \textit{``Dhaka Quiz Master''} beside the player's MSISDN on the leaderboard (500 XP).
\end{itemize}

\subsection{6. Telco Data Packs and bKash Digital Vouchers}
Through deep integration with Bangladesh telcos (GP Digimart, Robi, Banglalink) and bKash, high-loyalty contestants can convert digital XP into real-world value:
\begin{itemize}
    \item \textbf{Telco Internet Packs:} 500 MB 4G data bundle for \textbf{1,000 XP}.
    \item \textbf{bKash Cashback Vouchers:} 20 BDT mobile recharge discount coupon for \textbf{1,500 XP}.
\end{itemize}

\subsection{7. XP Redemption Ledger Architecture}
All XP debits follow strict double-entry principles. An atomic transaction ensures points are deducted from the user's balance and logged in the immutable ledger before perks are provisioned:

\begin{lstlisting}[language=SQL, caption={PostgreSQL Schema for XP Redemption and Feature Debits}]
-- XP Redemption Ledger Table
CREATE TABLE participant_xp_redemption (
    id BIGSERIAL PRIMARY KEY,
    msisdn VARCHAR(15) NOT NULL,
    portal_id INT NOT NULL DEFAULT 15,
    feature_type VARCHAR(50) NOT NULL, -- 'extra_round', 'streak_freeze', 'lifeline_50_50', 'vip_entry'
    xp_spent INT NOT NULL CHECK (xp_spent > 0),
    balance_before INT NOT NULL,
    balance_after INT NOT NULL,
    metadata JSONB DEFAULT '{}'::jsonb,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_xp_redemption ON participant_xp_redemption (msisdn, feature_type, created_at DESC);
\end{lstlisting}

\section{Real-World Scenario: Sabina's 15-Day Streak Journey}
In Dhaka, Sabina commits to playing Quizard every morning during her MRT transit:

\begin{enumerate}
    \item \textbf{Days 1--6:} Sabina earns $+20\text{ XP}$ each day alongside her daily first-play bonuses.
    \item \textbf{Day 7:} Unlocks the \textbf{Week 1 Champion} bronze badge alongside her $+20\text{ XP}$ daily bonus.
    \item \textbf{Days 8--14:} Her streak continues consistently ($+20\text{ XP}$ per day).
    \item \textbf{Day 15 (The Giant Surge):} Sabina logs in and completes her morning round. The backend triggers the giant 15th-day milestone, crediting $\mathbf{+520\text{ XP}}$ ($+20\text{ XP} \text{ daily base} + 500\text{ XP} \text{ milestone surge}$), elevating her to Player Level 18, and awarding the coveted \textbf{Half-Month Titan} platinum badge.
    \item \textbf{Day 16:} Sabina continues her unbroken streak, receiving $+20\text{ XP}$ as her journey towards the 30-day milestone begins.
\end{enumerate}

\begin{tcolorbox}[summarybox, title={Chapter Key Takeaways}]
\begin{itemize}
    \item The consistent daily streak model ($+20\text{ XP/day}$) rewards regular engagement with an easy-to-understand progression.
    \item The giant 15th-day milestone surge ($+500\text{ XP}$, total $+520\text{ XP}$) delivers a major gratification climax that dramatically curbs mid-month churn.
    \item The immutable XP ledger guarantees auditable, tamper-proof tracking of all gamification rewards.
\end{itemize}
