\chapter{The Performance Rating Architecture: 6 Score Bands, Dynamic Deltas, and Progression Modeling}

\begin{tcolorbox}[storybox, title={The Rating Engine in Brief}]
A contestant's skill rating is bounded strictly as an \textbf{integer on the 0 to 60 tournament scale} ($0 \le R \le 60$). Instead of raw score spikes or decimal fractions, Quizard implements an integer-based asymmetric dynamic rating engine. Every round score ($S \in \{0, 1, \dots, 60\}$) dynamically pulls the player's integer rating up or down, directly determining their active competitive rank tier.
\end{tcolorbox}

\section{The Integer Dynamic Rating Update Formula}
Upon completing a round with raw score $S_{t+1} \in \{0, \dots, 60\}$, the integer delta $\Delta R$ is calculated from the score gap $\Delta S = S_{t+1} - R_t$:

\begin{equation}
\Delta R = 
\begin{cases} 
0 & \text{if } S_{t+1} = R_t \\
\max\left(1, \, \text{round}\big(0.20 \cdot (S_{t+1} - R_t)\big)\right) & \text{if } S_{t+1} > R_t \\
\min\left(-1, \, \text{round}\big(0.35 \cdot (S_{t+1} - R_t)\big)\right) & \text{if } S_{t+1} < R_t \text{ and } S_{t+1} \ge 20 \\
\min\left(-2, \, \text{round}\big(0.45 \cdot (S_{t+1} - R_t)\big)\right) & \text{if } S_{t+1} < 20 \quad \text{(Severe Drop Penalty)}
\end{cases}
\end{equation}

The updated integer rating $R_{t+1}$ is clamped strictly between 0 and 60:

\begin{equation}
R_{t+1} = \text{clamp}\big(0, \, 60, \, R_t + \Delta R\big)
\end{equation}

\subsection{Core Principles of the Integer Engine}
\begin{itemize}
    \item \textbf{Strict Integer Scale ($0 \le R \le 60$):} All ratings, deltas, and score bands are whole integers, ensuring clean display on mobile badges and profile cards.
    \item \textbf{Guaranteed Movement:} When a player outperforms their rating ($S > R$), they gain at least $+1$ rating point. When they underperform ($S < R$), they lose at least $-1$ point.
    \item \textbf{Asymmetric Penalty:} Quitting or scoring $<20$ triggers an aggressive integer penalty ($\ge -2$ up to $-10$), preventing casual resets.
\end{itemize}

\subsection{Detailed Analysis of Each Case}
\begin{enumerate}
    \item \textbf{Case A: Score 32 (Slightly Below Rating):}
    $$\Delta S = 32 - 34 = -2 \implies \Delta R = -1 \implies R_1 = 34 - 1 = \mathbf{33}$$
    \textit{Outcome:} Rating gently softens from 34 to 33, remaining securely within the Specialist band ($30-39$).

    \item \textbf{Case B: Score 36 (Slightly Above Rating):}
    $$\Delta S = 36 - 34 = +2 \implies \Delta R = +1 \implies R_1 = 34 + 1 = \mathbf{35}$$
    \textit{Outcome:} Beating current expectation awards $+1$ point, climbing to 35.

    \item \textbf{Case C: Score 38 (Strong Specialist Round):}
    $$\Delta S = 38 - 34 = +4 \implies \Delta R = +1 \implies R_1 = 34 + 1 = \mathbf{35}$$
    \textit{Outcome:} High accuracy sustains upward momentum toward the 40 Expert boundary.

    \item \textbf{Case D: Score 52 (Master Breakout Performance):}
    $$\Delta S = 52 - 34 = +18 \implies \Delta R = \text{round}(0.25 \times 18) = +5 \implies R_1 = 34 + 5 = \mathbf{39}$$
    \textit{Outcome:} Scoring 52 correct produces an immediate $+5$ leap to 39. In the next round, if Mahir scores 55:
    $$\Delta S = 55 - 39 = +16 \implies \Delta R = +4 \implies R_2 = 39 + 4 = \mathbf{43} \quad (\text{Promoted to Expert!})$$

    \item \textbf{Case E: Score 12 (Severe Drop / Abandonment):}
    $$\Delta S = 12 - 34 = -22 \implies \Delta R = \text{round}(0.45 \times -22) = -10 \implies R_1 = 34 - 10 = \mathbf{24}$$
    \textit{Outcome:} Quitting early triggers the severe $-10$ integer penalty, immediately demoting the player from 34 down to \textbf{24 (Apprentice)}.
\end{enumerate}

\section{Database Schema and API Architecture}

\subsection{1. PostgreSQL Historical Rating Table}
\begin{lstlisting}[language=SQL, caption={PostgreSQL Schema for Integer Rating History}]
CREATE TABLE participant_rating_history (
    id BIGSERIAL PRIMARY KEY,
    msisdn VARCHAR(15) NOT NULL,
    portal_id INT NOT NULL DEFAULT 15,
    event_id INT NOT NULL,
    round_score INT NOT NULL, -- 0 to 60
    rating_before INT NOT NULL CHECK (rating_before BETWEEN 0 AND 60), -- e.g. 34
    rating_delta INT NOT NULL,  -- e.g. +1, -1, +5, -10
    rating_after INT NOT NULL CHECK (rating_after BETWEEN 0 AND 60),   -- e.g. 35 (strictly integer 0 to 60)
    band VARCHAR(30) NOT NULL, -- 'Novice', 'Apprentice', 'Specialist', 'Expert', 'Master', 'Grandmaster'
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_rating_history_lookup ON participant_rating_history (msisdn, portal_id, created_at DESC);
\end{lstlisting}

\begin{tcolorbox}[summarybox, title={Chapter Key Takeaways}]
\begin{itemize}
    \item The rating $R$ and band boundaries are strictly integers between $0$ and $60$, providing clean, intuitive alignment with the 60-question game format.
    \item Dynamic integer rounding guarantees immediate feedback ($\ge \pm 1$ point on performance delta) while preventing fractions or decimals.
    \item Consistent high-accuracy tournament scores elevate contestants to Master ($50-59$) and Grandmaster ($60$).
\end{itemize}
